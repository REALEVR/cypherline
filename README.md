# Cypherline

One AI-generated beat. Many voices, recorded separately, each taking a verse. Cypherline aligns every take to the rhythm and compiles them into one continuous 3–4 minute track — a crowdsourced cypher built on a shared instrumental.

Full project brief: [`docs/PROJECT_BRIEF.md`](docs/PROJECT_BRIEF.md) — read it before writing product code. Two things need settling before real work starts: what Suno's terms actually allow here, and the contributor consent/licensing model.

## Status

Pre-scaffold. No app code yet. First build target is the rhythm-matching pipeline (beat-grid detection + fit scoring) — the part the rest of the product depends on actually working.
